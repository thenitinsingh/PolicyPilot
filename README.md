# PolicyPilot

PolicyPilot is an HR-focused RAG assistant that answers questions
using information retrieved from a custom knowledge base.

## Current Features

- PDF-based knowledge base
- Document chunking
- Hugging Face embeddings
- FAISS vector store
- Groq LLM
- RAG-based question answering
- HR scope guardrail
- Source display
- Streamlit interface
